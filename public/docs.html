Reaction API

Gunakan API key akun pada header X-API-Key atau Authorization: Bearer.

POST /api/v1/reaction

curl -X POST https://DOMAIN-ANDA/api/v1/reaction \\
-H "X-API-Key: rak_xxxxxxxxx" \\
-H "Content-Type: application/json" \\
-d '{"url":"https://whatsapp.com/channel/...","reaction":"❤️"}'

Response sukses

{
  "success": true,
  "message": "Reaction berhasil diproses.",
  "coin_used": 1,
  "coin_remaining": 99,
  "task": {},
  "vip": {}
}

Rules

  • 1 successful request = 1 coin.
  • Failed upstream request tidak memotong coin.
  • Minimal custom top-up 100 coin.
  • Custom coin harus kelipatan 100.
