Reaction API

API untuk mengirim reaction menggunakan API key akun Anda.

BASE URL

Production

https://reaction-api-store.vercel.app
AUTHENTICATION

API Key

Gunakan API key akun Anda melalui header X-API-Key. 

RELS-REACTION-XXXX

Contoh di atas hanya placeholder. Gunakan API key milik Anda dari halaman Dashboard.

ENDPOINT

POST /api/v1/reaction

https://reaction-api-store.vercel.app/api/v1/reaction
REQUEST

cURL

curl -X POST https://reaction-api-store.vercel.app/api/v1/reaction \
-H "X-API-Key: RELS-REACTION-XXXX" \
-H "Content-Type: application/json" \
-d '{"url":"https://whatsapp.com/channel/...","reaction":"❤️"}'
EXAMPLE

JavaScript

const response = await fetch(
  "https://reaction-api-store.vercel.app/api/v1/reaction",
  {
    method: "POST",
    headers: {
      "X-API-Key": "RELS-REACTION-XXXX",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      url: "https://whatsapp.com/channel/...",
      reaction: "❤️"
    })
  }
);

const data = await response.json();

console.log(data);
EXAMPLE

Python

import requests

url = "https://reaction-api-store.vercel.app/api/v1/reaction"

headers = {
    "X-API-Key": "RELS-REACTION-XXXX",
    "Content-Type": "application/json"
}

data = {
    "url": "https://whatsapp.com/channel/...",
    "reaction": "❤️"
}

response = requests.post(
    url,
    headers=headers,
    json=data
)

print(response.json())
PARAMETERS

Request Body

url
URL target yang ingin diberi reaction.
string
reaction
Emoji reaction yang ingin dikirim.
string
COIN SYSTEM

Penggunaan Coin

Setiap request reaction yang berhasil menggunakan 1 coin.

Jika request ke upstream gagal, coin akan dikembalikan secara otomatis.
